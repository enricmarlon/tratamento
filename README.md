## Supabase Authentication

Create a Supabase project and enable email/password authentication. Disable public sign-ups under Authentication > Providers > Email, then provision authorized users from the Supabase dashboard.

Copy `.env.example` to `.env.local` and set `SUPABASE_URL` and `SUPABASE_PUBLISHABLE_KEY` from your project's Connect dialog. Restart the development server after changing environment variables. Set the same values as server-side secrets in production.

The app protects its routes with verified Supabase claims and refreshes sessions through Next.js `proxy.ts`. Auth cookies are HTTP-only, same-site, and secure in production. Never place the Supabase `service_role` key in this application.
